# Restored Minecraft Logo Animation

A Fabric client-side mod for Minecraft 26.1.2 that recreates the old flying/falling-block construction animation using the modern Minecraft logo.

## Minecraft

* **Minecraft:** 26.1.2
* **Mod Loader:** Fabric
* **Java:** 25
* **Environment:** Client-side

## What it does

When the Minecraft title screen appears, pieces of the Minecraft logo fly in and assemble into the finished logo.

The mod uses the actual Minecraft logo artwork rather than a recreated version.

Once the animation finishes, the normal Minecraft logo remains on the title screen.

## Features

* Flying-block logo construction animation
* Actual Minecraft logo artwork
* Adjustable animation speed
* Adjustable construction chunk size
* Configurable replay behavior
* Animation can be disabled
* Settings saved between launches
* Mod Menu configuration screen

## Building

You need:

* Java 25
* Fabric Loom
* An internet connection for Gradle to download dependencies

From the project folder, run:

```
gradlew build
```

The finished JAR will be created in:

```
build/libs/
```

For a clean build:

```
gradlew clean build
```
